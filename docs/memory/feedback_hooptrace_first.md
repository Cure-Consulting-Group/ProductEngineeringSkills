# HoopTrace-first measurement

**Rule:** Pilot the shared cloud product-agent platform on HoopTrace's web box score, PDF, and game-data consistency first. Scope Initiated Recruiting as the next product with its own product-specific plan, cost and measurement design.

**Why:** HoopTrace has approved game fixtures, reproducible correctness checks, and enough development activity to test both review quality and founder coordination time. Initiated Recruiting has different risk and outcome measures; do not treat the two products as identical or charge a second shared platform build.

**How:** Consult the latest [sprint plan](../planning/cloud-product-agents/sprint-plan.md), run a controlled/current-workflow comparison after read-only and repair gates, and carry the shared platform forward to a separate Recruiting integration scope. Revalidate this sequencing when user direction or product state changes.
