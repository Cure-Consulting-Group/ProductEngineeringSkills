# Cloud product agents

Design a shared cloud service with product manager, design, engineering and independent QA review roles. HoopTrace is the first measured pilot. Initiated Recruiting is the second product and now has its own scope, architecture, incremental cost model, six-sprint breakdown and evaluation gates. The Recruiting plan starts after the HoopTrace G7 decision and supersedes the provisional shared Sprint 9 Recruiting slice. No launch date or fixed monthly spending ceiling has been set. Current plans are proposals; no runtime has been deployed by this planning work.

The system should automatically gather evidence and prepare reviewable work, while human ownership remains on product strategy, sensitive production changes and releases. Track founder effort, agent spend and confirmed outcomes. See [planning pointers](reference_cloud_agent_plans.md) and verify current repository state before acting.
