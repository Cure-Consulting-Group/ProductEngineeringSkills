# Dissolution Checklist & Document Intake

## What I need to start — send these first

```
IDENTITY
[ ] Full legal name of the organization
[ ] EIN
[ ] State and date of incorporation (NY assumed)
[ ] IRS determination letter — exempt under 501(c)(?) and public charity vs
    private foundation classification
[ ] Certificate of incorporation + all amendments
    → specifically the DISSOLUTION CLAUSE
[ ] Bylaws → is it a MEMBERSHIP corporation? (changes the approval required)

FINANCIAL POSITION
[ ] Most recent balance sheet — what assets remain, and what liabilities
[ ] Bank statements for the current year
[ ] List of any restricted funds or donor-restricted gifts
    → restricted assets may have to follow the restriction, not the plan
[ ] Any real property, vehicles, or titled assets
[ ] Outstanding debts, leases, or contracts

FILING HISTORY
[ ] Last three Forms 990 / 990-EZ / 990-N as filed
[ ] Confirmation the organization is NOT already auto-revoked
    (three consecutive missed years → Sec. 6033(j))
[ ] NY Charities Bureau registration number, and last CHAR500 filed
[ ] Current tax year end (calendar or fiscal)

PEOPLE
[ ] Current board roster
[ ] Were there ever employees?  → final 941/940/W-2, NYS-45
[ ] Were there contractors paid $600+/$2,000+?  → final 1099-NECs

DECISIONS ALREADY MADE
[ ] Has the board voted to dissolve? Date and copy of the resolution
[ ] Intended recipient of remaining assets — name and EIN
    → must be a 501(c)(3) or a government entity
[ ] Target dissolution date
```

## Which track applies

```
Are there assets remaining after paying liabilities?

NO  → simplified dissolution track                        [VERIFY current process]
      · Plan of Dissolution stating no assets
      · Certificate of Dissolution to DOS
      · Final 990-N or 990-EZ marked final

YES → approval track
      · Plan of Dissolution and Distribution of Assets
      · NY Attorney General (Charities Bureau) review and approval
        (or NY Supreme Court if the AG declines to approve)
      · Certificate of Dissolution to DOS with approval attached
      · Distribute, obtain receipts
      · Final CHAR500 + final 990-series with Schedule N
```

## Working checklist

### Phase 1 — Establish the facts
```
[ ] Confirm exempt status is current (not auto-revoked)
[ ] Confirm all prior-year 990s were filed — identify any gaps
[ ] Confirm Charities Bureau registration status and CHAR500 history
[ ] Read the dissolution clause in the certificate of incorporation
[ ] Determine membership vs non-membership corporation
[ ] Identify restricted vs unrestricted assets
[ ] Identify any unresolved payroll tax exposure
```

### Phase 2 — Authorize
```
[ ] Board adopts Plan of Dissolution and Distribution of Assets
[ ] Member approval obtained if required by the bylaws
[ ] Resolution documents the recipient organization and its 501(c)(3) status
[ ] Minutes signed and dated
```

### Phase 3 — Settle
```
[ ] All liabilities identified and paid or provided for
[ ] Contracts and leases terminated
[ ] Final payroll run, if applicable
[ ] Creditors paid BEFORE any charitable distribution
```

### Phase 4 — State approval and filing
```
[ ] Plan submitted to NY AG Charities Bureau                    [VERIFY route]
[ ] AG approval received in writing
[ ] Certificate of Dissolution filed with NY Department of State [VERIFY form]
[ ] Filing receipt retained
```

### Phase 5 — Distribute
```
[ ] Assets transferred per the approved plan
[ ] Written receipt from each recipient, with their EIN
[ ] Bank accounts closed, final statements retained
```

### Phase 6 — Final federal filings
```
[ ] Final Form 990 / 990-EZ / 990-N — "Final return/terminated" box CHECKED
[ ] Schedule N completed (990/990-EZ) — asset-by-asset distribution detail
[ ] Certified Certificate of Dissolution attached
[ ] Plan of Dissolution attached
[ ] Board resolution attached
[ ] Final 941 (final-return box + recordkeeper statement), 940, W-2/W-3
[ ] Final 1099-NECs
[ ] Final NYS-45; deregister NY withholding and UI
```

### Phase 7 — Close out
```
[ ] Cancel state and local registrations, permits, licenses
[ ] Cancel insurance
[ ] Records archived — permanent file
[ ] Registered agent terminated
```

## Timing note

The final 990 is due the 15th day of the 5th month after the **termination date**,
so the termination date drives the deadline. If the AG approval and Certificate of
Dissolution land late in the year, the final return may not be due until well into
the following year — but **do not let that delay the substantive work**, since
reconstructing asset-distribution detail after the fact is far harder than
capturing it as it happens.
