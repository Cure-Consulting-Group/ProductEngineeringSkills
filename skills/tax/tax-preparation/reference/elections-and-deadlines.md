# Elections & Their Deadlines

**Late relief column is the one that matters.** Elections marked "None" are gone
forever if missed — no §9100 relief, no amended return, no reasonable cause.

## Absolutely unforgiving

| Election | Section | Deadline | Late relief |
|---|---|---|---|
| **§83(b)** | §83(b)(2) | **30 days from transfer** | **None.** Send certified mail, keep the receipt, attach a copy to the return. Form 15620 may be used. |
| **§41(h) payroll offset** | §41(h) | On the **timely filed original return** | **None** — cannot be made on an amended return |
| **NY PTET** | NY Tax Law Art. 24-A | **March 15 of the tax year** | **None.** Annual and irrevocable |
| **Form 8850 (WOTC)** | §51 | **28 days from hire** | **None** |
| **§1045 QSBS rollover** | §1045 | 60 days from sale | None |
| **§1031 exchange** | §1031(a)(3) | 45-day ID / 180-day close | None |
| **§475(f) mark-to-market** | §475(f) | Due date of the **prior** year's return | None — wait a full year |

## Accounting method changes — Form 3115

Not an election; a **method change** requiring consent.

- Automatic consent changes under Rev. Proc. 2015-13 and its successors: file
  Form 3115 with the return, copy to the IRS.
- **§481(a) adjustment**: negative (taxpayer-favorable) taken entirely in the year
  of change; positive spread over four years.
- Common triggers: **§174A retroactive relief** for 2022–2024 domestic R&E,
  adopting a **§471(c)** inventory method at a small inventory business, or a
  cash-to-accrual change once gross receipts cross the §448 threshold.

## Statement requirements

An election is not made by intending it. Most require a **statement attached to
the return** identifying:

1. The taxpayer name and TIN
2. The Code section and regulation under which the election is made
3. The property, activity, or amount to which it applies
4. The tax year
5. A signature where required

File the statement in `07_ELECTIONS/` with proof of timely filing. For §83(b),
the certified mail receipt **is** the proof and is the only thing that will save
the election if the IRS has no record.

## Election review — run before finalizing any return

```
[ ] Any stock issued subject to vesting this year?      → §83(b), 30 days
[ ] Any research credit and low tax liability?          → §41(h), original return only
[ ] Any pass-through with state tax and NY nexus?       → PTET, March 15
[ ] Any new hires from targeted groups?                 → Form 8850, 28 days
[ ] Any asset additions?                                → §179 / bonus elect-out
[ ] Written capitalization policy in place since Jan 1? → de minimis safe harbor
[ ] Any new entity formed?                              → 8832 / 2553; §1244 papers
[ ] Any QSBS sold within the year?                      → §1045, 60 days
[ ] Any method change contemplated?                     → Form 3115
[ ] Prior-year elections still binding and consistent?  → grouping, aggregation
```
