# Compliance Calendar — Tax Year 2026

Federal dates for tax year 2026. **Weekend and holiday shifts apply** — a
deadline landing on a Saturday, Sunday, or legal holiday moves to the next
business day, and that shift is not applied below.

The *Who* column names the **role**, not a company. Map the roles to the actual
entities in the project's tax profile once, then work the calendar off that.
State rows here are New York and Delaware examples of a pattern every state has;
substitute the real states of formation and nexus.

## 2026

| Date | Obligation | Who |
|---|---|---|
| **Jan 15** | Q4 prior-year estimated payment due | Individual |
| **Jan 31** | W-2 to employees **and** to SSA | Any entity with payroll |
| **Jan 31** | 1099-NEC to recipients **and** to IRS | Any entity paying contractors |
| **Jan 31** | 1099-MISC to recipients | Any entity paying rents, awards, other §6041 items |
| **Feb 28 / Mar 31** | 1099-MISC to IRS (paper / e-file) | Same |
| **Mar 1** | **State annual report + franchise tax** (Delaware's date; others vary) | Each entity, in its state of incorporation |
| **Mar 15** | **PTET election — irrevocable in most states, no late relief** | Each pass-through, per state |
| **Mar 15** | Form 1065 + K-1s to partners | Multi-member LLCs, partnerships |
| **Mar 15** | Form 1120-S + K-1s | S corporations |
| **Mar 15** | Form 7004 extension for 1065 / 1120-S | If needed |
| **Apr 15** | **Q1 estimated payment** | Individual, corporations |
| **Apr 15** | Form 1120 (prior year) or Form 7004 extension | C corporations |
| **Apr 15** | Form 1040 (prior year) or Form 4868 | Individual |
| **Apr 15** | IRA / HSA contribution deadline for the prior year | Individual |
| **Jun 15** | **Q2 2026 estimated payment** | Individual, corps |
| **Sep 15** | **Q3 2026 estimated payment** | Individual, corps |
| **Sep 15** | Extended Form 1065 / 1120-S | If extended |
| **Oct 15** | Extended Form 1120 / 1040 | If extended |
| **Dec 31** | **401(k) plan must be ADOPTED for 2026 deferrals** | any sponsoring entity |
| **Dec 31** | Last day for most 2026 tax-year actions: asset placed in service, charitable gifts, Roth conversions, loss harvesting | all |

## Rolling / event-driven

| Trigger | Deadline |
|---|---|
| Stock issued subject to vesting | **§83(b) within 30 days** |
| New hire from a targeted group | Form 8850 within 28 days |
| QSBS sold, rollover desired | §1045 within 60 days |
| Property sold, §1031 intended | 45-day ID / 180-day close |
| New entity formed | 8832 (75 days retro) / 2553 (2mo 15d); §1244 papers at issuance |
| Contractor engaged | **W-9 before first payment** — otherwise 24% backup withholding |
| Payroll established | 941 quarterly, 940 annually, deposit schedule per lookback |

## Standing reminders

- Extensions extend **filing**, never **payment**.
- 10+ information returns in aggregate must be **e-filed via IRIS**.
- §6721/§6722 penalties are per form, and the recipient copy and IRS copy are
  separate failures.
