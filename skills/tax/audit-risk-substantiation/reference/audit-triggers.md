# Audit Triggers & Portfolio Exposure

Used to decide **where to invest documentation effort** — never to decide whether
to take a position (Circular 230 §10.37).

## How returns get selected

| Mechanism | What it is |
|---|---|
| **DIF score** | Discriminant function — statistical model scoring a return against norms for its income class and business type. Outliers score high. |
| **UIDIF** | Unreported income DIF — estimates income not reported. |
| **Document matching (AUR)** | Automated: W-2s, 1099s, K-1s, 1098s matched to the return. Generates CP2000 notices, not audits. **The highest-volume contact by far.** |
| **Related examination** | A partner, related entity, or transaction counterparty is examined. **Directly relevant to a multi-entity structure — one exam can pull in the others.** |
| **Compliance initiatives** | Focus areas: high-income non-filers, S corp officer comp, cryptocurrency, cannabis, syndicated conservation easements, micro-captives, ERC claims. |
| **Whistleblower / referral** | §7623 claims. |

## Structural triggers in a founder-owned group

Work down this list against the actual entities and record which ones are live,
where, and what evidence exists. Rank by exposure in *this* group rather than by
generic frequency — a trigger nobody in the group has is not a finding.

| Trigger | Typically present at | Mitigation |
|---|---|---|
| **Consecutive business losses** | Any activity with a personal-interest product, and any company still pre-revenue | §183 profit-motive file: business plan, separate books, documented pricing changes, time logs. Build it now, not at examination. |
| **S corp / closely held officer comp** | Any S corp, and any C corp once it starts payroll | Comp study *before* the year, board resolution, written memo retaining the comparables |
| **R&D credit** | Any company claiming §41 | A high-scrutiny credit. Project-level four-part-test documentation and time allocation. Under-claiming does not reduce scrutiny — a credit with no wage QREs looks anomalous. |
| **Cannabis / §280E** | Any licensed or pre-licence cannabis activity | A standing IRS compliance initiative. COGS allocation set up **before** operations, never reconstructed |
| **Related-party transactions** | Any group where one entity serves another | Written intercompany agreements, benchmarked method, actual invoicing **and payment** (§482) |
| **Home office + vehicle** | Individual | §274(d) contemporaneous logs; exclusive-use evidence |
| **Large deductions relative to income** | Any pre-revenue or early-stage entity | The narrative must be coherent. A pre-revenue studio is a legitimate story — write it down while it is still true. |
| **Cash-intensive / merchant reporting mismatch** | Retail, and any app or platform revenue | Reconcile merchant reports to revenue; explain 1099-K differences in writing |
| **Multi-state / residency** | Any entity formed in one state and operating in another | Day counts, domicile factors; residency audits are aggressive in high-tax states |
| **New entity + IP transfer** | Any spinout | §351 contemporaneous documentation and valuation support |
| **QSBS exclusion at exit** | Any C corp whose founders expect §1202 | Evidence captured **at issuance** — gross assets, qualified-trade memo. Cannot be reconstructed later. |

## The narrative test

Read the return as a stranger with no context. Does it tell a coherent story?

Anomalies are not the problem — **unexplained** anomalies are. A services company
reporting nominal revenue alongside a large research credit is unusual. That is
fine if the file contains: what the company is building, why revenue is low, what
the R&D actually was, and how the credit was computed. It is a problem if the file
contains none of that.

Write the narrative into the workpapers every year. It costs an hour and it is the
first thing an examiner asks for.

## Documentation investment tiers

Match effort to exposure.

| Tier | Positions | Investment |
|---|---|---|
| **Routine** | Standard deductions, clearly documented ordinary expenses | Normal records |
| **Elevated** | Home office, vehicle, meals, §179 elections, QBI | Contemporaneous logs + computation workpapers |
| **High** | R&D credit, reasonable comp, intercompany pricing, §183-exposed losses, Augusta rule | Third-party support (study, benchmark, appraisal, venue quotes) + FIRAC memo before filing |
| **Maximum** | QSBS qualification, §351 IP transfer, §280E COGS allocation, residency change | Outside counsel opinion, valuation, and a permanent evidence file |

## Notice types — know which one arrived

| Notice | What it is | Response |
|---|---|---|
| **CP2000** | Automated matching proposal. **Not an audit.** | Agree or disagree in writing with documents, by the deadline. Often resolved on paper. |
| **CP2501** | Earlier-stage matching inquiry | Same |
| **Letter 566 / correspondence exam** | Limited-scope exam by mail | Answer exactly what is asked, with documents |
| **Office exam** | In-person at an IRS office, broader | Representation advisable |
| **Field exam** | Revenue agent at the business, broadest | **Representation required.** Do not host unrepresented |
| **30-day letter** | Proposed adjustments + appeal rights | Protest to Appeals within 30 days |
| **90-day letter (statutory notice of deficiency)** | Final determination | **Tax Court petition within 90 days — jurisdictional, cannot be extended** |

## Standing hygiene

```
[ ] Separate bank accounts and books per entity — no commingling, ever
[ ] W-9 collected before the first payment to any contractor
[ ] Contemporaneous logs for all §274(d) categories
[ ] Annual written narrative in the workpapers explaining the year
[ ] Board minutes for every non-routine corporate action
[ ] Intercompany agreements signed, invoiced, and actually paid
[ ] Entity names correct on every contract, 1099, and app-store agreement
[ ] Basis and carryforward schedules current
[ ] QSBS evidence captured at each issuance, not at exit
```
