# Circular 230 / SSTS Engagement Checklist

Run at engagement start, before filing, and after filing. Record the date and who
performed each check.

## Engagement start

```
[ ] Scope defined in writing — entities, years, services included and excluded
[ ] Competence assessed (§10.35) — anything requiring outside expertise identified
    (cannabis §280E, QSBS qualification, DE/NY multistate, transfer pricing)
[ ] Conflicts identified and documented (§10.29)
    [ ] Multi-entity conflicts: intercompany pricing is adverse between entities
    [ ] Written waivers obtained where required — retain 36 months
[ ] PTIN current (if signing for compensation)
[ ] §7216 consents obtained for any disclosure or use beyond return preparation
    [ ] Third-party/API processing of return information covered
[ ] Prior-year returns obtained and reviewed (SSTS No. 3)
[ ] Carryforward attributes captured from prior year
[ ] Fee arrangement — no contingent fee on an original return (§10.27)
```

## During preparation

```
[ ] All source documents received and reconciled
    [ ] W-2s, 1099s (NEC/MISC/INT/DIV/B/R/K), K-1s, 1098s
    [ ] 1099 totals reconciled to reported gross receipts — differences explained
    [ ] Bank/merchant deposits reconciled to revenue (Stripe, Apple, direct)
[ ] All return questions answered (SSTS No. 2) — none left blank
    [ ] Foreign account / FBAR questions
    [ ] Virtual currency question
    [ ] Schedule C vehicle questions (do you have evidence? is it written?)
[ ] Due diligence inquiries made where information appears
    incorrect / inconsistent / incomplete (§10.34, SSTS No. 3)
    [ ] Each inquiry, answer, and date logged
[ ] Estimates used only where permissible and reasonable (SSTS No. 4)
    [ ] NOT used for any §274(d) strict-substantiation item
    [ ] Not presented with false precision
[ ] Each non-routine position evaluated against the standard
    [ ] Substantial authority documented, OR
    [ ] Reasonable basis + Form 8275/8275-R prepared, OR
    [ ] Position not taken
[ ] Economic substance screen run on every planning item (§7701(o))
[ ] §6695(g) due diligence completed if EITC / CTC / AOTC / HoH — Form 8867
[ ] All elections identified, prepared, and deadline-checked
[ ] Reasonable compensation supported if any S corp or closely held corp
```

## Pre-filing review

```
[ ] Return reconciles to workpapers, line by line
[ ] Book-to-tax reconciliation complete (Schedule M-1/M-2 for 1120)
[ ] Carryforward schedule updated and rolled forward
[ ] Prior-year comparison — every material variance explained in writing
[ ] Diagnostics cleared or consciously accepted with a note
[ ] Estimated payments and withholding agree to transcripts/records
[ ] State return(s) consistent with federal; decoupling adjustments made
    [ ] NY: §280E decoupling, PTET credit, ITC coordination
    [ ] DE: franchise tax computed under the favorable method
[ ] Disclosures attached where required (8275, 8886, 8832, 8283)
[ ] Reviewer sign-off with date — not the same pass as preparation
```

## Filing and after

```
[ ] Taxpayer reviewed and approved before transmission
[ ] Copy furnished to taxpayer (§6695(a)-(b))
[ ] Preparer signature and PTIN present, if applicable
[ ] E-file authorization (8879) signed and retained
[ ] Proof of timely filing retained (acknowledgment or certified mail receipt)
[ ] Elections filed and proof retained — §83(b) especially: certified mail receipt
[ ] Return and workpapers archived per retention schedule (§6107(b): 3 years)
[ ] Basis, QSBS, and carryforward records moved to permanent storage
[ ] Next-year planning items and deadlines calendared
```

## Error discovery (SSTS No. 6, §10.21)

```
[ ] Client informed promptly, in writing
[ ] Consequences of the error explained (tax, interest, penalties)
[ ] Corrective action recommended (amended return, VDP, qualified amended return)
[ ] Client's decision documented
[ ] IRS NOT notified without client permission
[ ] If client refuses to correct a material error → evaluate withdrawal;
    document the decision either way
```

## Red flags requiring escalation to outside counsel or a CPA of record

- Any position with fraud exposure (§6663) or a possible criminal referral.
- Listed or reportable transactions (Form 8886).
- QSBS qualification opinions — the §1202(e) qualified-trade analysis for a
  health-adjacent software company.
- Transfer pricing methods for intercompany services at material amounts.
- Cannabis §280E positions beyond straightforward COGS.
- Residency/domicile change positions in a NY audit posture.
- Anything where the practitioner is also the beneficial owner and the amount is
  material — get an independent review.
